

# Chat Career Advisor

A Python-based chatbot designed to provide career advice and guidance to users. This project aims to simplify the career decision-making process by offering personalized recommendations and insights.

---

## Features
- **Personalized Career Advice**: Tailored recommendations based on user inputs.
- **Interactive Chatbot**: Engages users in a conversational format.
- **Scalable Architecture**: Built with Python for flexibility and extensibility.

---

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/Mahmedorabi/Chat_career_advisor.git
    cd Chat_career_advisor
    ```

2. (Optional) Create and activate a virtual environment:
    ```bash
    python -m venv venv
    source venv/bin/activate  # For Linux/Mac
    venv\Scripts\activate     # For Windows
    ```

3. Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```

---

## Usage

1. Run the chatbot:
    ```bash
    python main.py
    ```

2. Interact with the chatbot by following the prompts.
